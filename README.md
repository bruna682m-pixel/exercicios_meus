# Exercícios de Lógica de Programação em Python

Este repositório reúne os exercícios que desenvolvi durante meus estudos de **Lógica de Programação** utilizando **Python**.

O objetivo deste projeto é registrar minha evolução, praticar a resolução de problemas e consolidar os principais conceitos da programação antes de avançar para tópicos mais complexos.

---

## Conteúdo estudado

Até o momento, os exercícios abordam:

* Entrada e saída de dados (`input` e `print`)
* Variáveis e tipos de dados
* Operadores aritméticos
* Operadores relacionais e lógicos
* Estruturas condicionais (`if`, `elif`, `else`)
* Estruturas de repetição (`while`)
* Uso do `break`
* Validação de entrada de dados
* Construção de algoritmos

---

## Exercícios desenvolvidos

Entre os exercícios presentes neste repositório estão:

* Média ponderada de alunos
* Cálculo de fatorial
* Verificação de número primo
* Conversão de número decimal para binário
* Conversão de segundos para horas, minutos e segundos
* Equação do segundo grau (Bhaskara)
* Verificação do tipo de triângulo
* Ordenação de três números
* Cálculo de notas para um determinado valor em dinheiro
* Cálculo de crédito bancário
* Cálculo do custo de compra de maçãs
* Diversos exercícios de lógica utilizando condições e laços de repetição

---

## Objetivo

Este repositório tem como finalidade:

* Praticar lógica de programação.
* Desenvolver raciocínio algorítmico.
